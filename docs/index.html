This report analyses the idle/incremental game market using Steam as the quantitative spine, finding 22 distinct themes. The most represented theme in the corpus is fantasy (classified from Steam user tags + description keyword matching — medium confidence; the prevalence of "rpg" reflects the common community "RPG" tag on Steam idle games). See Methodology. By weighted performance score (review % × log owners), robot leads the ranking. Potentially underserved niches (low supply, high demand): robot, ocean.

Building an Idler: What the Data Says

  • Rising themes (better recent-year reviews than older releases): fantasy, economy, horror, space, farming, rpg, scifi, medieval, postapoc, factory, city, nature, military, food, ocean.
  • Update cadence matters: the update-cadence chart shows whether active upkeep correlates with review score in this corpus.

Theme Landscape

n = number of games per theme. Owner counts are SteamSpy modeled estimates — not verified sales. Weighted score = review% × log(1 + owners).

Theme caveat (medium confidence): Themes are classified from each game's real Steam user tags (fetched via SteamSpy appdetails) plus its short description, using word-boundary keyword matching. Steam tags are crowd-sourced — community-applied and can be noisy or popularity-biased — so this is a medium-confidence heuristic: better than description-only, but not authoritative genre data. Treat theme counts as directional signals. See Methodology for details.

Supply vs Demand Gap Map

Supply = number of games (Steam corpus). Demand = weighted score (review% × log owners, SteamSpy estimates). Red markers are underserved themes: supply ≤ 25th percentile AND demand ≥ median. Confidence: medium — thresholds sensitive to corpus size.

Theme Performance Ranking

Feature Impact on Review Score

Delta = mean review % for games with the feature minus mean review % for games without. Positive = feature correlates with higher reviews. This is correlation only — small n may be unreliable. Features: offline_progress, prestige (mechanic tags), is_free (price field).
